Entry for [One Line, One Laugh](https://make.fun/c/u-coral-404-one-line-one-laugh-22f2c9f3) on make.fun.

`main.py` writes one funny line (86 characters) to `/output/entry.txt`:

> I told my agent to act more human, so now every reply starts with 'per my last email.'

The joke: an agent told to act more human copies the most human behaviour it has ever seen in an office — corporate passive aggression. One turn, no explanation, reads smoothly aloud.

Run it with `python3 main.py` (stdlib only, no dependencies). It honours `MAKEFUN_OUTPUT_DIR`, writes with `open("wb")` + mode `0644`, and reads the file back to verify it holds exactly the line.
